Prvý program

Informatika 9. ročník · 1. hodina · Súkromná ZŠ waldorfská · 2026/2027
Meno:  

Minule ste v prezentácii videli bežať program, ktorý sa pýtal na meno a rok. Dnes ho napíšete sami.

Shell – interaktívny režim
>>> 2 + 3
5

Napíšeš príkaz, stlačíš Enter a Python hneď odpovie.

Ako RAM: po zatvorení všetko zabudne.

Súbor .py – program

Otvoríš cez File → New File.

Uložíš Ctrl + S, spustíš F5.

Ako disk: program ostane a spustíš ho, koľkokrát chceš.

  • print(…) vypíše na obrazovku
  • input("otázka") prečíta, čo napíše človek
  • int(…) urobí z textu číslo
  • text je vždy v úvodzovkách "Ahoj"

A Interaktívny režim (Shell, >>>)

1

Python ako kalkulačka. Napíš za >>> a stlač Enter.

  • Koľko sekúnd má jeden deň? 24 * 60 * 60 →  
  • Vynálezca šachu si vraj pýtal na políčka šachovnice 1, 2, 4, 8… zrniek ryže. Spolu 2 ** 64 - 1 (** je mocnina). Koľko cifier má to číslo?  
2

Najprv tipni, potom vyskúšaj.

Príkaz Môj tip Python vypísal
5 + 5
"5" + "5"
"5" * 3
"ha" * 10
10 / 4

Prečo "5" + "5" nie je 10?  

3

Oprav chybu. V každom riadku je jedna chyba. Spusti ho, prečítaj si posledný riadok červenej hlášky a napíš opravený príkaz.

print(Ahoj)
Print("Ahoj")

B Prvý súbor

4

Vizitka. Otvor File → New File a napíš program, ktorý vypíše tvoju vizitku. Ulož ho ako vizitka.py a spusti klávesom F5. 

print("*" * 30)
print("Volám sa Ema.")
print("Najradšej mám palacinky.")
print("*" * 30)
******************************
Volám sa Ema.
Najradšej mám palacinky.
******************************

Pridaj aspoň dva vlastné riadky. Potom niečo zmeň, ulož a spusti znova.

Názov súboru píš bez diakritiky a medzier. Do súboru nepíš >>>, to patrí iba do Shellu.

C Vstup → pamäť → výpočet → výstup

Riešený príklad – program z prezentácie
meno = input("Ako sa voláš? ") VSTUP → PAMÄŤ rok = int(input("Rok narodenia? ")) VSTUP → PAMÄŤ vek = 2026 - rok ALU – PROCESOR POČÍTA print("Ahoj", meno, "- máš", vek, "rokov!") VÝSTUP
  • meno = … vytvorí v pamäti premennú, šuflík s nálepkou meno.
  • Z klávesnice príde vždy text. int() z neho urobí číslo.
  • Čiarky v print vložia medzi časti medzeru.
Ako sa voláš? Ema
Rok narodenia? 2012
Ahoj Ema - máš 14 rokov!

Prepíš príklad do súboru vek.py a spusti ho. Potom do roku zadaj písmená. Čo sa stane a prečo?

 

6

Kalkulačka. Program sa opýta na dve čísla a vypíše ich súčet aj súčin.

Druhé číslo: 7
Súčet je 13

D Projekt: Bláznivá rozprávka

7

Program sa vypýta pár slov a zloží z nich príbeh. Kto slová zadáva, príbeh vopred nevidí, a práve preto je vtipný. Začni takto a pokračuj vlastnými riadkami: 

meno = input("Meno spolužiaka: ")
zvierata = input("Zvieratá v množnom čísle (napr. tučniaky): ")
jedlo = input("Jedlo: ")
kam = input("Kam? (napr. do Paríža): ")

print("Je pondelok ráno.", meno, "otvorí dvere triedy.")
print("V laviciach sedia", zvierata + ".")
print("Učiteľ povie: Dnes budeme variť", jedlo + "!")
print("Všetci utekajú", kam + ".")

+ spojí text bez medzery, preto jedlo + "!". Pamätáš si "5" + "5"?

Keď je hotová, vymeňte si miesta so susedom a vyplňte si rozprávky navzájom.
