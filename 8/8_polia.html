Pracovný list č. 8 – Polia (zoznamy) v Pythone

9. ročník ZŠ – Informatika

🏠 Späť na zoznam pracovných listov

1️⃣ Čo je zoznam?

Zoznam (list) je premenná, ktorá uchováva viacero hodnôt v poradí. Zapisujeme ho do hranatých zátvoriek: 

znamky = [1, 2, 1, 3, 1, 2]
mena = ["Anna", "Boris", "Cyril"]
prazdny = []

Každý prvok má svoje číslo – index. Indexovanie začína od nuly:

# index:   0    1    2    3    4    5
znamky = [ 1,   2,   1,   3,   1,   2 ]

2️⃣ Čítanie a zápis prvkov

farby = ["červená", "modrá", "zelená"]

print(farby[0])    # červená  (prvý prvok)
print(farby[2])    # zelená   (tretí prvok)
print(len(farby))  # 3        (počet prvkov)

farby[1] = "žltá"  # zmena druhého prvku
print(farby)       # ["červená", "žltá", "zelená"]

Záporné indexy

pole[-1] je skratka za pole[len(pole) - 1] – teda posledný prvok. Python si sám dopočíta pozíciu od konca: 

farby = ["červená", "modrá", "zelená"]   # len(farby) = 3

farby[-1]   # = farby[3 - 1] = farby[2] → "zelená"
farby[-2]   # = farby[3 - 2] = farby[1] → "modrá"

3️⃣ Prechádzanie cyklom

mena = ["Anna", "Boris", "Cyril"]

# Cez prvky:
for meno in mena:
    print(meno)

# Cez index:
for i in range(len(mena)):
    print(i, mena[i])
Reťazec je ako pole znakov. S textom vieme pracovať rovnako – pristupovať cez index, prechádzať cyklom aj použiť len(): 
slovo = "Python"

print(slovo[0])    # P
print(slovo[-1])   # n
print(len(slovo))  # 6

for pismeno in slovo:
    print(pismeno)

4️⃣ Reťazenie a opakovanie

Zoznamy sa dajú spájať operátorom + a opakovať operátorom *:

a = [1, 2, 3]
b = [4, 5, 6]

print(a + b)     # [1, 2, 3, 4, 5, 6]   (spojenie)
print([0] * 5)   # [0, 0, 0, 0, 0]      (opakovanie)

Takto vieme pridať prvok na koniec aj bez append() – stačí spojiť zoznam s jednoprvkovým zoznamom: 

cisla = [10, 20, 30]
cisla = cisla + [40]
print(cisla)   # [10, 20, 30, 40]

Alebo pridať prvok na začiatok:

cisla = [10, 20, 30]
cisla = [5] + cisla
print(cisla)   # [5, 10, 20, 30]

5️⃣ Slicy (výrezy)

zoznam[od:do] – vráti časť zoznamu (od je zahrnuté, do nie). 

c = [10, 20, 30, 40, 50, 60, 70]

c[1:4]    # [20, 30, 40]
c[:3]     # [10, 20, 30]          (od začiatku)
c[4:]     # [50, 60, 70]          (do konca)
c[::2]    # [10, 30, 50, 70]     (každý druhý)
c[::-1]   # [70, 60, ..., 10]    (pozpiatku)

6️⃣ Pridávanie a mazanie prvkov

PríkazČo robí
z.append(x)pridá x na koniec
z.insert(i, x)vloží x na index i
z.remove(x)odstráni prvý výskyt hodnoty x
z.pop()odstráni a vráti posledný prvok
z.pop(i)odstráni a vráti prvok na indexe i
del z[i]zmaže prvok na indexe i
cisla = [10, 20, 30]
cisla.append(40)       # [10, 20, 30, 40]
cisla.insert(1, 15)    # [10, 15, 20, 30, 40]
cisla.remove(20)       # [10, 15, 30, 40]
cisla.pop()            # [10, 15, 30]

7️⃣ Kópia zoznamu

a = [1, 2, 3]
b = a        # b ukazuje na TEN ISTÝ zoznam – nie je to kópia!
b.append(4)
print(a)     # [1, 2, 3, 4]  – zmenilo sa aj a!

Skutočná kópia:

a = [1, 2, 3]
b = a[:]       # skutočná kópia

b.append(4)
print(a)       # [1, 2, 3]     – a sa nezmenilo!
print(b)       # [1, 2, 3, 4]  – zmenilo sa iba b

Kópiu vieme vytvoriť troma spôsobmi – všetky robia to isté:

b = a[:]       # slice kópia
b = list(a)    # cez list()
b = a.copy()   # cez .copy()

✔ Mal/a by si vedieť:

  • vytvoriť zoznam a pristupovať k prvkom cez index
  • zmeniť, pridať a zmazať prvok
  • prejsť zoznam cyklom for
  • použiť slice a správne skopírovať zoznam
