1️⃣ Čo je podmienka?

Podmienka v Pythone umožňuje rozhodnúť sa, ktorý blok kódu sa vykoná. Najjednoduchšia podmienka používa príkazy if a else.

2️⃣ Základný tvar podmienky

if podmienka:
    # tento kód sa vykoná, ak je podmienka pravdivá
else:
    # tento kód sa vykoná, ak podmienka nie je pravdivá

Príklad:

cislo = int(input("Zadaj číslo: "))

if cislo > 0:
    print("Číslo je kladné.")
else:
    print("Číslo je záporné alebo nula.")
Úlohy:
  1. Napíš program, ktorý načíta tvoje meno a číslo. Ak je číslo väčšie ako 10, vypíše: 
    Ahoj <meno>, tvoje číslo je veľké!
    Inak vypíše: 
    Ahoj <meno>, tvoje číslo je malé.
  2. Opýtaj sa používateľa na vek. Ak má 18 a viac, vypíš „Si dospelý.“ Inak „Ešte nie si dospelý.“
  3. Opýtaj sa na dve čísla. Zisti, ktoré je väčšie. Použi >, < alebo ==.

3️⃣ Operátory porovnávania

==   je rovné
!=   nie je rovné
>    väčšie
<    menšie
>=   väčšie alebo rovné
<=   menšie alebo rovné
Úlohy na precvičenie:
  1. Opýtaj sa používateľa na heslo. Ak zadá python, vypíš „Správne!“. Inak vypíš „Nesprávne heslo.“
  2. Načítaj dve čísla a vypíš, či sú rovnaké alebo nie.
  3. Napíš program, ktorý zistí, či je číslo záporné, kladné alebo nula. Použi if a else.

5️⃣ Rozšírenie: Podmienka elif

Keď potrebujeme viac ako dve možnosti, použijeme elif. Je to skratka pre „else if“. 

cislo = int(input("Zadaj číslo: "))

if cislo > 0:
    print("Číslo je kladné.")
elif cislo < 0:
    print("Číslo je záporné.")
else:
    print("Číslo je nula.")
Úlohy:
  1. Napíš program, ktorý sa opýta na počet bodov (0–100) a vypíše známku podľa tabuľky:
    • 90–100 → „Výborný“
    • 70–89 → „Chválitebný“
    • 50–69 → „Dostatočný“
    • 0–49 → „Nedostatočný“
  2. Program načíta vek. Ak máš:
    • 0–5 → „Malé dieťa“
    • 6–14 → „Žiak“
    • 15–17 → „Tínedžer“
    • 18+ → „Dospelý“
    Použi if + elif + else.
