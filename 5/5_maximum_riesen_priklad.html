Pracovný list č. 5 – Riešený príklad: Nájdenie maxima troch čísel

❓ Zadanie

Napíš program v Pythone, ktorý má na vstupe 3 čísla a zistí, ktoré z nich je najväčšie.

Príklad vstupu:

  • Číslo 1: 5
  • Číslo 2: 12
  • Číslo 3: 8

Očakávaný výstup: Maximálne číslo je 12

✅ Riešenie (vnorené if-else podmienky)

1. Krok – Pochopenie logiky

Potrebujeme porovnávať 3 čísla. Základná idea:

  • Ak je číslo 1 väčšie ako číslo 2 a väčšie ako číslo 3 → maximum je číslo 1
  • Inak, ak je číslo 2 väčšie ako číslo 1 a väčšie ako číslo 3 → maximum je číslo 2
  • Inak → maximum musí byť číslo 3

2. Krok – Diagram toku rozhodovania

Máme 3 čísla: a, b, c
↓
Je a > b AND a > c ?
├─ AÑO → maximum = a ✓
└─ NIE
    ↓
    Je b > c ?
    ├─ AÑO → maximum = b ✓
    └─ NIE → maximum = c ✓

3. Krok – Kompletný Python kód

a = int(input("Zadaj prvé číslo: "))
b = int(input("Zadaj druhé číslo: "))
c = int(input("Zadaj tretie číslo: "))

if a > b and a > c:
    maximum = a
else:
    if b > c:
        maximum = b
    else:
        maximum = c

print(f"Maximálne číslo je {maximum}")

4. Krok – Krok za krokom vysvetlenie

Riadok 1-3: Čítame tri čísla od používateľa a konvertujeme ich na typ int (celé číslo).
Riadok 5: Hlavná podmienka: if a > b and a > c:
  • Skontrolujeme, či je číslo a väčšie než všetci ostatní
  • Ak áno, vieme, že a je určite maximum
  • Operátor and znamená, že obe podmienky musia byť pravdivé
Riadok 6: Ak je podmienka pravdivá, priradíme: maximum = a
Riadok 7-11: Vnorené if-else (vykonáme len ak riadok 5 bol nepravdivý)
  • if b > c: → Ak je b väčšie ako c, potom b je maximum
  • else: → V opačnom prípade musí byť maximum c
Riadok 13: Vypíšeme výsledok pomocou f-stringu (formátovaného reťazca): f"Maximálne číslo je {maximum}"

5. Krok – Testovanie s príkladmi

Vstup (a, b, c) Vykonanie kódu Výstup
5, 12, 8 5 > 12? NIE → 12 > 8? AÑO → maximum = 12 Maximálne číslo je 12
20, 10, 5 20 > 10 AND 20 > 5? AÑO → maximum = 20 Maximálne číslo je 20
3, 7, 15 3 > 7? NIE → 7 > 15? NIE → maximum = 15 Maximálne číslo je 15
8, 8, 8 8 > 8? NIE → 8 > 8? NIE → maximum = 8 Maximálne číslo je 8

🔄 Alternatívne spôsoby riešenia

1️⃣ Pomocou vnorených if-else (náš kód)

if a > b and a > c:
    maximum = a
else:
    if b > c:
        maximum = b
    else:
        maximum = c

Výhody: Jasné, ľahko pochopiteľné

Nevýhody: Viac riadkov kódu

2️⃣ Pomocou funkcie max()

a = int(input("Číslo 1: "))
b = int(input("Číslo 2: "))
c = int(input("Číslo 3: "))

maximum = max(a, b, c)
print(f"Maximum je {maximum}")

Výhody: Krátky a elegantný kód

Nevýhody: Netrénujem logiku s podmienkami

3️⃣ Pomocou reťazených porovnaní

if a > b and a > c:
    maximum = a
elif b > a and b > c:
    maximum = b
else:
    maximum = c

Výhody: Jasnejší kód, elif je modernejší

Nevýhody: Podobný ako prvý spôsob

4️⃣ Pomocou zoznamu a funkcie sorted()

cisla = [a, b, c]
cisla_zoradene = sorted(cisla)
maximum = cisla_zoradene[-1]
print(f"Maximum je {maximum}")

Výhody: Funguje pre ľubovolný počet čísel

Nevýhody: Zložitejšie, menej efektívne

💡 Prečo sme použili vnorené if-else?

  • Pedagogický dôvod: Cvičíme logické myslenie a pochopenie podmienok
  • Jasnosť: Vidíme presne, ako sa rozhodovací proces vyvíja
  • Základy: V programe sa bez vnorených podmienok neobídeme
  • Porovnanie: Vidíme rozdiely medzi rôznymi prístupmi
